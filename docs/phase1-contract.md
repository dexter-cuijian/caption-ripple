# Phase1 authoritative integration protocol

Node22+, sherpa-onnx-node2.0.1. Server HTTP http://127.0.0.1:9876; WS /ws/v1/session. Supersedes Python portions of protocol.md. Original JSON subtitle event compatible. Extension-origin allowlist: chrome-extension://[a-p]{32}; reject arbitrary web origins; localhost native CLI no Origin permitted with token. .runtime/token random32bytes base64url chmod0600; server prints path only. Pair token entered popup, storage.local (never sync). Health no authentication; capabilities token Bearer. Hello token first within5s.

hello {type:'hello',protocolVersion:1,token,sessionId,epoch:0,sourceLanguage:'auto'|'zh'|'en',targetLanguage:'en',mode:'fast',video:{id,url,title,currentTime:number|null,live:boolean,playbackRate:1}}; ready {type:'ready',sessionId,epoch,engine:'sherpa-onnx/paraformer',sampleRate:16000}. Optional context/glossary later compatible.

Each audio packet starts JSON {type:'clock',sessionId,epoch,seq:number,capturedAt:Date.now(),sampleStart:number,mediaTime:number|null,playbackRate:number,paused:false}, immediately followed binary int16 littleendian mono16000Hz <=100ms/3200bytes. Capture timestamp describes END of packet. sampleStart counts samples since epoch start. Server binds JSON metadata to next binary, validates seq/epoch; never reads JS TypedArray backing buffer outside offset/length. Max audio queue20 chunks (2s) plus WS backpressure cap; reset explicit on dropping audio so no silent unbounded accumulation.

Server subtitles {type:'subtitle',sessionId,epoch,segmentId:string,revision:number,phase:'interim'|'final',sourceText:string,sourceLanguage:'zh'|'en'|'auto',start:number,end:number,mediaTime:number|null,createdAt:number,engine:string,speechStartAt:number|null,audioEndAt:number,timestampKind:'capture-estimate',metrics:{decodeMs:number,queueMs:number}}. start/end audio seconds since epoch start, estimated interval not per-token timestamps (paraformer has none). interim identical text suppressed; final ALWAYS finalizes same segment once and increments segment for next utterance; >=0.5sec silence endpoint. Final transcript stored session memory for phase1 download diagnostics; IndexedDB stage4.

Client {type:'reset',sessionId,epoch:newEpoch,mediaTime,reason}, {type:'pause'|'stop',sessionId,epoch}; resume uses reset with epoch++. Reset ack {type:'reset',sessionId,epoch}. Server {type:'status',level,code,message,...}; errors never fabricate transcript. Send {type:'rendered',sessionId,epoch,segmentId,revision,renderedAt,hasTranslation:false} back to server for end-to-end JSONL diagnostics. Auth token excluded logs, logs capped/rotated. WS disconnect: extension capture remains alive and audio replay remains connected; reconnect starts fresh epoch, no replay old audio.

Runtime envelope {target:'background'|'offscreen'|'content'|'popup',kind:string,...}. Popup commands start/stop/get-state; background orchestrates current tab offscreen and routes source events to all permitted content frames. Content each frame discovers its best video and renders own overlay for chosen video or bottom viewport fallback. fullscreenchange moves host into fullscreen element except void video where native full screen DOM overlay limitation is surfaced. state includes {phase:'idle'|'connecting'|'running'|'reconnecting'|'error',message,tabId,sessionId,epoch,rms,framesSent,latestText}. Offscreen publishes audio meter and server status. Source overlay bottom center, black translucent background white text. DOM changes/SPA detect and reposition without audio restarts. popup config stored chrome.storage.sync, pairing token storage.local only.
