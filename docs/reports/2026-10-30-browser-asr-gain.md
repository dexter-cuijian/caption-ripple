# 浏览器内识别音量归一化对比 · 2026-10-30

使用与扩展相同的 Sherpa-ONNX WASM/模型、`BrowserAsrSession`、16 kHz/100 ms PCM 输入，以及本机保留的 FLEURS validation 参考音频。每段独立建流；以最终识别文字计算英文词错率（WER）和中文字符错率（CER）。原始音频及逐条结果仅在忽略的 `.work/` 目录，不进入公开仓库。

| 目标 RMS | 英文 40 段 / 339.86 秒，811 词 | 中文 28 段 / 330.42 秒，930 字 |
| --- | --- | --- |
| 0.02 | 487/811，60.05% WER | 未测 |
| 0.05，原设定 | 279/811，34.40% WER | 99/930，10.65% CER |
| 0.08 | 211/811，26.02% WER | 未测 |
| 0.12 | 177/811，21.82% WER | 未测 |
| 0.16，候选 | 167/811，20.59% WER | 100/930，10.75% CER |
| 0.20 | 164/811，20.22% WER | 未测 |

0.16 相对原设定大幅改善安静英文语音，中文变化为多错 1 字。选用 0.16 并保留 0.98 峰值上限；0.20 仅比 0.16 少 3 个英文词错误，暂无足够证据值得继续提高目标增益。新增测试验证安静片段提升和响亮片段不削波。

同一段约 74 秒真实中文新闻音频的两个输出只有小幅差异；没有独立完整参考文本，不能计算新闻 CER，也不能把本表当作真实 Chrome 延迟、标点、专名或翻译质量验收。英文专用官方 WASM 模型可能是后续候选；目前尚未取得可测的模型数据文件，不能宣称优于现有模型。
