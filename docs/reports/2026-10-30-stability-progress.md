# CaptionRipple 稳定版验收进度 · 2026-10-30

当前发布状态：预览版。稳定版尚未通过验收。

## 本轮已验证

- 侧栏默认先显示实时字幕和本页历史；导入字幕、术语表、翻译准备收在可展开的“辅助工具”中。实际 Chrome 中检查了折叠与展开。
- 在用户提供的无网页字幕视频 `2reQut8WNGc` 中，浏览器内 WASM 识别启动成功，实时英文原文、中文译文和侧栏历史同时出现；停止后采集结束。该视频的识别和译文仍有明显错词与长句问题。
- 浏览器 worker 的积压包数有上限，超限会重启识别并建立新 epoch；普通重置需等待 worker 回报完成。模拟慢解码和网页字幕结束后的恢复测试通过。
- 停止或重置会把未定稿的历史从“识别中”转为“未定稿”，并保留原文；停止时也清理旧版本遗留的临时记录。
- 网页字幕逐字增加和窗口滚动时，重叠词在同一短时片段中合并。自动测试通过；真实网页滚动字幕仍需复验。用户提供的 `R1ECMLrwDYQ` 在本次 Chrome 播放中显示“无法显示字幕”，不能作为这一项的实测证据。
- `npm run typecheck`、`npm run test:extension`（87 项）、`npm run build`、`git diff --check` 通过。服务端 61 项在允许 `127.0.0.1` 测试监听的环境下通过；默认沙箱禁止监听回环端口。

## 稳定版仍需完成

- 用明确的可复现音频和字幕参考，改善浏览器内识别的错词、专有名词、标点与长句分段；核对中文译文质量。
- 在真实 Chrome 复验网页字幕滚动、历史去重、导入字幕、暂停、跳转、全屏和关闭网页字幕后的回退。
- 完成多站点和连续两小时运行，记录内存、CPU、音频回送、识别积压与延迟。
- 做干净安装包、许可、隐私、无服务安装与公开下载复核；全部通过后才能标记稳定版。
