# Live Caption Translator — approved design

User-approved scope: Chrome MV3 extension + local Mac companion, local first with optional cloud; English/Japanese/Korean/Cantonese to Simplified Chinese, revisable draft then final subtitles. Install in this Mac's Chrome and verify real tab-audio capture.

Deliver complete source, locked dependencies, model setup and start/stop tools, unpacked extension, docs and evidence. Full feature scope: capture/pass-through/16kHz PCM, stream ASR and translation, Shadow DOM overlay, player selection and cross-frame discovery, pause/seek/rate/end/navigation handling, fullscreen and Document PiP, side panel, persistent/searchable/exportable/deletable history, subtitle/translation cache, scoped glossary, asynchronous knowledge annotations with provenance, local OCR and optional vision API.

Architecture: TypeScript/Vite/React extension. Python 3.12/FastAPI/WebSocket companion. WhisperLiveKit MLX ASR; Chrome Translator draft with local Hy-MT2 1.8B Q4_K_M context/terminology translation; optional Ollama/OpenAI-compatible models. Keys in macOS Keychain. Bind loopback only, validate extension Origin and pairing token. No external upload by default.

Performance gates: warm interim source P95<=1.5s; meaningful first Chinese draft P95<=1.5s from aligned audio chunk end; finalized Chinese P95<=3s from utterance end. Actual capture-to-render timestamps, P50/P95 and cold start separated. English clear-speech WER<=15%; >=5 min of real reference speech each EN/JA/KO/YUE; >=50 translated sentences checked for negation/numbers/proper nouns. Actual public live stream + YouTube + Bilibili + local + iframe + multi-video, >=60 min stability; fault recovery and 0.5/1/1.5/2x playback. Do not mark unmeasured or failing gates passed.

Environment verified: Apple M1 16GB, macOS 27.0.1, Chrome 156; 28GiB available. Model downloads on demand; avoid installing all engines simultaneously. Work only in new project directory. New branch feature/realtime-captions. No push/publish requested.
